# Cashier Queue Simulator

Simple web-based cashier queue simulator built with React + Vite.

Features:
- Add customers to a FIFO queue
- Assign next customer to cashier with the fewest customers
- Assign all customers at once
- Responsive, modern UI

Run locally:

```bash
npm install
npm run dev
```
